Secure, customizable Python for Excel

xlpro is a lightweight Python wrapper for Excel. Distribute Python functionality alongside your spreadsheets.
Download
Available for Office 365 and Excel 2021+ on Windows 10/11

Functions

Features

User Defined Functions

Define Excel equations in Python using your favourite libraries and call them from Excel asynchronously. Link your arguments to ranges as you normally would, and let Excel's recalculation cycle issue recalcuation requests as the function arguments update.

By default, your return values are given as Python objects. Pass and return these as you normally would in a Python script

Need to inspect the contents of a Python object? - Just use the show() function to expand the array contents dynamically into Excel.

Learn more →

Dynamic Python-Driven Assets

Need bespoke plotting functionality? - xlpro's show_image() function will to export your image-like objects matplotlib.figure.Figure dynamically into Excel.

As the arguments of the plotter function update, Excel will naturally issue recalcuation and update your figure.

You aren't dealing with a conventional figure? - That's fine, show_image() supports simple paths, so you can always bring your data into Excel.

Editor & Debugging Integrations

Native support for VSCode workspaces. Simply run the pre-configured and dynamic debug configuration to debug your functions while the Python server is running.

Need support for other debugging formats? Reach out!

Distribution

Your code and configurations are kept in a folder adjacent to your target workbook. requirements.txt and .python-version are updated dynamically as the workbook is saved.

Need to install a new package? Leverage the VSCode default interpreter path setting and open a terminal and just run pip install. xlpro will manage the rest.

Sharing a document with a colleague? All they need to do is re-initialze the workbook on their machine and xlpro will ensure their environment matches yours before any code runs.
