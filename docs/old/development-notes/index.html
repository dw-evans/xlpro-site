    Installer /xlpro_installer

    Essentially a zip archive including the required files, such as the add-in and cli tool.

    The only installer function is to add the installation folder to the user path path.

    Command-Line /xlpro_cli

    The CLI tool manages creation and tracking of python environments using uv.exe.

    Is essentially a suite of CLI tools necessary for the Excel add-in to manage and interact with the Python COM servers. 

    xlpro-cli start

    xlpro-cli init

    xlpro-cli guid
